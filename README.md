# dotfiles

Everything running on my desktop, in one place. `~/.config` symlinks into here, so edit files here and that's what runs.

- `quickshell/wavegoo` — the bar + start menu (`qs -c wavegoo`)
- `quickshell/goonotes` — sticky notes, file cabinet, corkboard (bar buttons start it)
- `quickshell/hourglass` — sand timer (bar button starts it)
- `quickshell/visits` — portfolio visit counter. Needs `admin.json`, which is not in git (private key).
- `alacritty/`, `autostart/`

Fresh machine: `./install.sh`
